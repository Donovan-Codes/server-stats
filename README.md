# server-stats

A shell script that reports basic performance statistics for any Linux server.

Built from the [roadmap.sh](https://roadmap.sh/projects/server-stats) DevOps projects track.

---

## Usage

```bash
./server-stats.sh
```

No arguments. No dependencies beyond a standard Linux userland.

## What it reports

**Required**

- [ ] Total CPU usage
- [ ] Total memory usage — free vs used, including percentage
- [ ] Total disk usage — free vs used, including percentage
- [ ] Top 5 processes by CPU usage
- [ ] Top 5 processes by memory usage

**Stretch**

- [ ] OS version
- [ ] Uptime
- [ ] Load average
- [ ] Logged-in users
- [ ] Failed login attempts
